# SKYBURN v1.0

Fighter-jet combat flight sim that runs in your browser. Vanilla ES Modules + raw WebGL2 +
Web Audio + Gamepad API + IndexedDB. **No frameworks, no engines, no build tools beyond a
Python script - every asset is original and procedural** (golden rule from the PRD).

- 14 missions (M1-M14) across 8 procedural sectors + free-flight sandbox with carrier ops
- 42-jet hangar roster with stat bars, compare view and credit unlocks (incl. the SR-71)
- Guns / radar-missile lock / flares, 4-difficulty AI, Ace Bonus objectives
- 120 Hz fixed-timestep physics with render interpolation and seeded RNG (deterministic
  replay), verified with TLA+ proofs, 10 000-run fuzz and property tests
- Installable PWA: **offline after the first visit**, saves in IndexedDB with
  export/import/clear, local top-5 high-score boards per mission

## Quick start

```bash
npm start          # serve the repo root (dev, raw sources) at http://localhost:8080
npm test           # headless test suite (node --test)
npm run build      # python build.py -> dist/ (minified, PWA-complete ship bundle)
npm run dev        # build + serve
```

Play the ship bundle: serve `dist/` over http (e.g.
`python -m http.server 8080 --directory dist`) and open
<http://localhost:8080>. Service-worker registration needs a secure context
(https or `localhost`).

## Repository layout

| Path | What |
|------|------|
| `index.html` | Single page: canvas + HUD DOM + screen overlays |
| `src/core/` | Loop (120 Hz), input (InputState), audio, save (IndexedDB), leaderboard, quality governor, profiler |
| `src/physics/`, `src/combat/` | 6DOF flight model, guns/missiles/lock/collision, SoA entity registry |
| `src/ai/` | Enemy AI + the shared FSM engine (one table per FSM) |
| `src/mission/` | Mission FSM, objective DAG, stages, spawner, Ace bonuses |
| `src/render/`, `src/world/` | Raw WebGL2 renderer, procedural terrain/ocean/carrier, kitbash jet meshes |
| `src/data/*.json` | Jets, weapons, missions, maps (data-driven content) |
| `src/verify/` | Runtime invariants (NaN/limits/pools) |
| `icons/`, `manifest.json`, `sw.js` | PWA (icons generated by `tools/gen_icons.py`) |
| `verify/*.tla` | TLA+ specs (Mission, Missile, Game FSMs) |
| `tests/` | Node test runner suite + fuzz driver + dist checks |
| `build.py` | Minifying ship build -> `dist/`, forbidden-import checks, size gates |
